# نصوص التعليق الصوتي — BR

٦١ جملة، كل جملة بملف صوت منفصل. الفيلم ينضبط تلقائياً على طول تسجيلاتك.

## الملفات

| الملف | شنو بيه |
| --- | --- |
| `BR_tts_lines.txt` | اسم الملف + النص، سطر لكل جملة. هذا الأساسي |
| `BR_tts_text_only.txt` | النصوص بس، سطر لكل جملة (للأدوات اللي تولّد دفعة وحدة) |
| `BR_tts_lines_diacritized.txt` | نفس النصوص بالتشكيل، إذا النموذج يقرأ أحسن بالحركات |
| `BR_tts_lines.csv` | جدول كامل: النص، النص المشكّل، الترجمة اللي تطلع على الشاشة، والمدة الحالية |

## ملاحظات للتوليد

- **الأسماء:** "BR" مكتوبة "بي آر"، و"Pera" مكتوبة "بيرا"، والسنين مكتوبة كلمات حتى النموذج ما يقراها أرقام.
- **اللهجة:** النص بالعراقي، و"چان / چانت" مكتوبة بالچ حتى تنلفظ صح.
- **"..."** معناها وقفة قصيرة. إذا النموذج ما يوقف، تكدر تولّد الجملة كقطعتين.
- **أسلوب الصوت:** رجالي، ناضج، هادئ وواثق، سرعة متوسطة، بدون حماس مبالغ بيه. نفس الصوت ونفس الإعدادات لكل الجمل.
- **الصيغة:** أي صيغة صوت تمشي (wav, mp3, m4a, ogg…). الأفضل wav أو mp3 بجودة عالية.

## التسمية

سمّي كل ملف برقم الجملة: `01.wav`، `02.wav` … إلى `61.wav`. أي اسم يبدي بالرقم يمشي، مثل `01.mp3` أو `1 - intro.wav`.
حط الكل بمجلد واحد وارسله.

## بعد ما توصل التسجيلات

```bash
python3 tools/import_vo.py مسار/المجلد
node render.mjs --cues out/cues.json
python3 tools/soundtrack.py out/cues.json out
# ثم إعادة الرندر والتجميع (شوف ../README.md)
```

الأداة تقص الصمت من البداية والنهاية، وتوحّد مستوى الصوت، وتعيد توقيت الترجمات والمشاهد على طول كل جملة.
